  1. Migrate 3 hardcoded credentials to a vault

  2. Add .env to .gitignore
     Adding .env to .gitignore prevents secrets from entering version
     control. Existing tracked .env files also need `git rm --cached
     .env`.
     $ opena2a protect

  3. Review and lock down MCP server permissions
     MCP servers with filesystem or shell access can read, modify, or
     delete files when invoked by an AI assistant. shield init walks
     each server, captures a signed baseline, and applies the
     recommended permission policy.
     $ opena2a shield init

  4. Exclude AI instruction files from git
     AI instruction files reveal tooling choices and system prompts
     when committed to a public repository. Adding them to
     .git/info/exclude keeps them local without modifying .gitignore.
     $ opena2a protect

  5. Sign config files for integrity monitoring
     Signed baselines let you detect unintended config changes before
     they affect runtime behavior.
     $ opena2a protect
